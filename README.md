# Joshua Asiribo — Portfolio Website

Personal portfolio built with Next.js 14, Tailwind CSS, and Google Fonts.

## Setup

```bash
npm install
npm run dev
```

## Deploy to Render
- Build: `npm install && npm run build`
- Start: `npm start`
- Node 18+

## Sections
- Hero — animated, floating code card, status badge
- Stats — 4 animated counters
- About — bio, certifications, quick facts
- Services — 6 service cards
- Projects — 4 live project cards with links
- Skills — 8 skill categories + certifications
- Contact — Upwork CTA + email
